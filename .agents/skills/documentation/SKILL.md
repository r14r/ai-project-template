# Documentation

1. Dokumentationsziel und maßgeblichen Quellcode/Sachstand prüfen.
2. Betroffene Seiten identifizieren; Widersprüche und Redundanz vermeiden.
3. Kompakte, überprüfbare Dokumentation mit Links auf Primärquellen schreiben.
4. Änderungen an Architekturentscheidungen als ADR mit Kontext und Alternativen festhalten.
5. `STATUS.md` nur mit datiertem, verifiziertem Status aktualisieren.
6. Links, Struktur und `just validate` überprüfen.

Keine erfundenen Informationen, URLs oder Testergebnisse übernehmen.
