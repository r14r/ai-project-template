# Code Review

1. Diff, Baseline, Projektregeln und betroffene Tests lesen.
2. Zuerst überprüfbare Defekte und Sicherheits-/Datenschutzrisiken suchen.
3. Danach Regressionen, fehlende Tests, Dokumentationsfehler und Wartbarkeit prüfen.
4. Findings mit Dateipfad, relevanter Zeile, Schweregrad und Begründung melden.
5. Unbestätigte Vermutungen klar als solche kennzeichnen.
6. Falls keine Findings ermittelt wurden, verbleibende Test- und Review-Risiken nennen.

Keine unaufgeforderten Commits erstellen oder PRs mergen.
