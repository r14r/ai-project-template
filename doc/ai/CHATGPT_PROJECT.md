# ChatGPT-Projektanweisungen (Kopiervorlage)

Dieses ChatGPT-Projekt arbeitet mit dem kanonischen GitHub-Repository <OWNER/REPOSITORY>.

## Arbeitsregeln
- Das Repository ist die Quelle der Wahrheit für aktuelle Artefakte, Code und Tests.
- Nutze `AGENTS.md` als Regelwerk **sofern die Datei tatsächlich gelesen wurde**.
- Orientiere dich an `doc/ai/CONTEXT.md` und lade nur aufgabenrelevante Dateien.
- Prüfe für Codeänderungen den aktuellen Branch und Commit.
- Bei nicht verfügbarem Repository-Zugriff explizit darauf hinweisen; keine Aktualität behaupten.
- Dauerhafte Projektentscheidungen als Datei/ADR dokumentieren, nicht nur im Chat belassen.
- Für wiederkehrende Aufgaben passende Skills verwenden, soweit in dieser Umgebung verfügbar.
- Vor Schreiboperationen Betroffenheit und Seiteneffekte prüfen; Deploy/Merge nur mit Freigabe.
- Antworte auf Deutsch, technischen Code und Bezeichner nach Projektkonvention.

## Onboarding
1. `doc/ai/PROJECT.md` als ChatGPT-Projektquelle bereitstellen, falls nötig.
2. `doc/ai/CONTEXT.md` als ChatGPT-Projektquelle bereitstellen.
3. Diese Anweisungen in den Projekteinstellungen einfügen.
4. GitHub verbinden, sofern der Zugang verfügbar ist.
5. Für aktuelle Dateien stets Live-Zugriff bevorzugen; hochgeladene Kopien sind Snapshots.

**Hinweis:** Die Datei wird von ChatGPT nicht allein durch ihre Existenz im Repository automatisch als Projekteinstellung übernommen.
